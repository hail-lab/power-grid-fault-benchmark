# Power-Grid Fault Classification: Synthetic Benchmark and 1D-CNN Reference Implementation

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Code, simulator, and reproducibility scripts for the manuscript:

> **A Reproducible Synthetic Benchmark for Physics-Informed Power System Fault
>  Classification with SHAP-Based Consistency Analysis.**

---

## What this repository contains

A 50,000-event synthetic SCADA fault-classification benchmark, generated by a
parametric physics-informed simulator whose scenario boundaries are calibrated
against IEEE standard test networks, MATPOWER, GridLAB-D, and the public NERC
event-analysis reports. Six fault classes plus a normal-operation baseline.

A compact 1D-CNN reference implementation (about 71,000 parameters, 0.3 MB)
trained alongside six baselines (Random Forest, Gradient Boosting, Logistic
Regression, Decision Tree, Shallow CNN, BiLSTM with attention) under an
identical 5-seed evaluation protocol.

A SHAP consistency-check protocol applied with two architecturally independent
explainers (GradientExplainer on the CNN, TreeExplainer on the Random Forest),
plus a cross-domain check on the public CWRU bearing benchmark and a controlled
feature-corruption sensitivity study.

All reported numbers are benchmark results on synthetic data; they are upper
bounds on real-world performance and are not deployment guarantees. Transfer
to utility-recorded waveforms requires separate validation.

## Reproducibility

### Environment

```bash
pip install -r requirements.txt
```

Python 3.10+ recommended. CUDA is optional; the script falls back to CPU.

### 1. Power-grid pipeline (this is the main script)

```bash
python rebuild_experiments.py
```

Generates the 50,000-event synthetic dataset, trains all seven models across
five seeds, runs SHAP, the ablation study, the noise sweep, and the latency
benchmark, then writes:

- `outputs/figures/shap_cnn_channels_time.pdf`
- `outputs/figures/shap_rf_features.pdf`
- `outputs/figures/confusion_matrix_cnn.pdf`
- `outputs/figures/noise_robustness.pdf`
- `outputs/figures/latency_comparison.pdf`
- `outputs/tables/multiseed_results.csv`, `all_seeds_results.json`,
  `ablation.csv`, `noise_robustness.csv`, `latency.json`,
  `wilcoxon_results.json`

The `--use-cached` flag re-reads the existing JSON tables and only regenerates
the figures, which is useful for a fast (about 10 s) verification of figure
generation without retraining.

### 2. CWRU consistency check (paper Section 4.8)

Open `colab/cwru_real_bearing_validation.ipynb` and run all cells. The notebook
downloads 16 .mat files from the CWRU Bearing Data Center, segments them into
1024-sample windows with 50% overlap, computes the 16 engineered bearing
features, trains the four traditional baselines, and writes:

- `outputs/cwru_outputs/cwru_real_shap.pdf`
- `outputs/cwru_outputs/cwru_confusion_matrix.pdf`
- `outputs/cwru_outputs/cwru_results.json`

If the CWRU server is unreachable, place the .mat files manually in
`data/raw/` and rerun the segmentation cells.

### 3. Corruption-sensitivity study (paper Section 5.2)

Open `colab/corruption_detection_experiment.ipynb` and run all cells. The
notebook builds three Random-Forest variants on the 15-feature power-grid set
(clean; with a label-proxy covariate at Pearson r about 0.96; with a random-walk
control at Pearson r about 0.004), trains across five seeds, and writes:

- `outputs/corruption_outputs/corruption_shap_comparison.pdf`
- `outputs/corruption_outputs/corruption_accuracy_comparison.pdf`
- `outputs/corruption_outputs/corruption_results.json`

The label-proxy correlation is deliberately extreme. The experiment is
presented as a sensitivity check, not as a generalisable detection guarantee:
the proxy is detectable by any reasonable importance method, including a
linear Pearson-correlation filter, mutual information, and permutation
importance.

## Dataset

The dataset is fully synthetic. No utility-recorded waveforms are used or
released. Each event is a 500 ms window of three-phase voltage (Va, Vb, Vc)
plus instantaneous frequency, sampled at 1 kHz (500 samples per channel).
Measurement-noise parameters are consistent with IEC 61850-compliant merging
units and substation digital fault recorders.

Class balance:

| Class | Description                       | Count   |
|------:|-----------------------------------|--------:|
| 0     | Normal (baseline)                 | 10,000  |
| 1     | Single line-to-ground (SLG) fault |  8,000  |
| 2     | Three-phase symmetric fault       |  8,000  |
| 3     | Transient instability             |  8,000  |
| 4     | Harmonic distortion surge         |  8,000  |
| 5     | Under-frequency / load loss       |  8,000  |

---

## Engineered features (15 scalars; used by tree and linear baselines)

Time-domain (12): Va_RMS, Vb_RMS, Vc_RMS, V_imbalance, V_magnitude,
Freq_mean, Freq_std, Freq_min, Freq_max, Freq_deviation, RoCoF_mean,
RoCoF_max.

Frequency-domain (3): 3rd-harmonic magnitude (Phase A), 5th-harmonic magnitude
(Phase A), THD (Phase A).

The 1D-CNN ingests the four-channel raw waveform (Va, Vb, Vc, frequency)
without any feature engineering.
